# 쿨라이프

에어컨 세척 고객 웹과 관리자 PWA. 대표 연락처는 010-4166-3703이며, 초기 가격은 비워 둡니다.

- 고객 웹: https://minjaedy.github.io/coollife/customer/
- 관리자: https://minjaedy.github.io/coollife/admin/
- API: https://coollife-api.couple-private-push.workers.dev

## 사용

고객은 에어컨 종류·수량, 희망 날짜·시간대, 주소, 이름, 연락처, 사진을 제출합니다. 신청마다 임의의 개인 조회번호가 발급됩니다. 조회번호 또는 개인 링크를 보관하면 로그인 없이 해당 신청만 확인할 수 있습니다. 조회번호를 다른 사람에게 전달하면 그 사람도 해당 신청을 볼 수 있습니다.

관리자 목록에서 현재 상태를 눌러 변경하거나 확인 시작·방문 확정·세척 완료 버튼으로 바로 처리할 수 있습니다. 방문 확정에는 금액과 일정이 필요하고, 신청 취소에는 확인 단계가 있습니다. 사진은 목록에서 미리 보고 눌러 확대할 수 있습니다.

관리자는 견적 승인, 금액·방문 시간 확정, 안내 메시지, 전화 요청, 진행 상태 변경과 비공개 메모를 사용할 수 있습니다. 메시지는 고객의 **내 견적 화면**에 표시되며 SMS는 발송하지 않습니다. 대표 번호를 누르면 사용자의 전화 앱이 열립니다.

가격표 관리에서 에어컨 종류, 가격, 항목별 할인 조건, 브랜드별 가격 안내, 공통 할인 안내를 수정합니다. 브랜드별 가격 안내는 각 에어컨 종류에 600자까지 여러 줄로 입력할 수 있고 고객 가격표와 관리자 단가·수량 보기에 표시됩니다. 비워 두면 고객에게 표시하지 않습니다. 브랜드별 안내 문구는 기본 금액에 자동 가산되지 않으며, 최종 견적 승인 시 관리자가 금액을 조정합니다. 빈 가격은 고객 화면에서 `—`로 보입니다. 가격표는 Firebase 스트림으로 고객 화면에 반영되고 연결 장애 시 주기적으로 다시 확인합니다. 기존 신청에는 접수 당시 서비스 정보가 남고, 최종 금액은 관리자가 따로 확정합니다. 할인 문구로 금액을 임의로 계산하지 않습니다.

Safari 공유 메뉴의 **홈 화면에 추가**, Chrome/Edge의 **앱 설치**로 설치할 수 있습니다. 고객 앱과 관리자 앱은 별도 manifest ID와 scope를 사용합니다. 개인 정보는 오프라인 캐시에 넣지 않으며 조회와 저장에 인터넷 연결이 필요합니다.

## 계정 및 구성

회사 계정·토큰·리소스는 사용하지 않습니다. 로컬 AGENTS.md의 경계를 따릅니다.

| 구성 | 전용 리소스 | 역할 |
|---|---|---|
| GitHub | `minjaedy/coollife`, `main:/docs` | 정적 화면, 설치 아이콘 |
| Firebase | `coollife-minjaedy` RTDB | 공개 가격표·사업장 안내만 저장 |
| Cloudflare Worker | `coollife-api` | 관리자 인증, 고객별 접근 검사, 견적 API |
| Cloudflare D1 | `coollife-crm` | 비공개 견적·사진·메모·진행 이력 |

Firebase 루트는 읽기·쓰기가 모두 차단되어 있고 `/public/catalog`만 공개 읽기를 허용합니다. 가격 수정은 Worker가 전용 서비스 계정으로 수행합니다. 고객 정보는 Firebase 공개 경로에 저장하지 않습니다. 개인 조회번호는 서버에 SHA-256 해시로만 저장됩니다. 관리자 전용 링크는 256비트 임의 키를 사용하고 서버 secret에는 그 SHA-256 해시만 저장합니다.

## 관리자 전용 링크

관리자는 비밀번호 대신 소유자에게 비공개로 전달하는 전용 링크로 접속합니다. 링크의 임의 키는 URL fragment로 전달하므로 웹 서버 요청 주소에 포함되지 않으며, 앱이 읽은 직후 주소창에서 제거합니다. 서버가 키를 검증한 뒤 기기에 저장해 다음 접속에도 자동으로 연결합니다. 일반 `/admin/` 주소만 아는 사람은 고객 정보를 볼 수 없습니다.

**전용 링크를 아는 사람은 관리자 권한을 갖습니다.** 고객에게 전달하지 말고 어머니와 운영자만 공유합니다. 일반 고객 웹에는 이 링크가 없습니다. 비공개 링크와 키를 저장소·이슈에 올리지 않습니다. 로그아웃은 현재 기기의 키를 지우며, 링크 자체는 재사용할 수 있습니다. 링크가 노출됐다면 새 임의 키를 만들고 Worker의 `ADMIN_LINK_HASH`를 교체하면 모든 기존 기기와 링크의 접근이 즉시 폐기됩니다. 다시 승인할 기기에만 새 링크를 전달합니다.

## 위치와 사진

주소 검색은 Kakao 우편번호 검색을 이용합니다. 현재 위치와 지도 클릭/드래그로 방문 위치를 조절하고 주소를 직접 수정할 수 있습니다. 지도는 Leaflet / OpenStreetMap이며 위치 정보는 사용자가 버튼을 누르고 허용할 때만 가져옵니다.

`KAKAO_REST_KEY`를 Worker secret으로 추가하면 지도 좌표를 도로명/지번 주소로 바꾸는 기능도 동작합니다. 키가 없는 초기 배포에서는 지도 핀과 주소 검색·직접 입력은 가능하지만 좌표의 주소 자동 변환은 제공되지 않습니다.

사진은 최대 3장, 장당 250KB로 브라우저에서 압축 후 서버에서 형식·용량을 다시 검사합니다. 원본 EXIF를 보관하지 않습니다. 사진 조회에도 해당 고객 조회번호나 관리자 인증이 필요합니다. 현재 사진은 D1 BLOB에 저장하므로 운영 규모에 맞춰 용량을 관찰하고 필요 시 별도 객체 저장소로 이전합니다. 견적·사진은 자동 삭제하지 않습니다. 무제한 저장을 약속하는 구조가 아닙니다.

만료 세션·요청 제한 카운터·주소 캐시는 하루 첫 API 접속 때 정리합니다. 추가 유료 cron을 만들지 않으며 사용하지 않는 동안 새 기록도 쌓이지 않습니다. 고객 화면은 안내를 15초마다 갱신하며 푸시 알림이나 SMS 기능은 포함하지 않습니다.

## 개발 및 검증

Node.js 24 이상에서 실행합니다. 로컬 가상 고객 데이터는 `.local/preview.sqlite`에만 있습니다.

```sh
npm ci
npm run dev
npm test
npm run check
npm run build
```

`http://127.0.0.1:8789/customer/`, `/admin/`에서 테스트합니다. 로컬 관리자 우회는 loopback 호스트와 `LOCAL_PREVIEW=1`이 모두 맞을 때만 허용되며 운영에는 해당 변수가 없습니다.

테스트는 관리자 전용 링크·키 교체에 따른 접근 폐기, 타 고객 사진 접근 차단, 비공개 메모 분리, 승인·전화 요청 표시, 중복 접수 방지, 가격표 수정 충돌, CORS와 만료 기록 정리를 확인합니다. 실제 아이폰 카메라·위치 권한과 설치는 해당 기기에서 확인해야 합니다.

## 배포

`npm run build`가 `public/`을 GitHub Pages용 `docs/`로 복사합니다. `docs/`에 비밀키, 런타임 DB, 고객 데이터를 넣지 않습니다.

Cloudflare 명령은 항상 `coollife-personal` 프로필, 개인 계정 `06bada574d14a5e1d912f35b4645f695`만 사용합니다. 배포 전 활성 계정의 이메일이 개인 Gmail인지 확인합니다. 다른 계정이면 중단합니다.

```sh
wrangler whoami --json
wrangler deploy --profile coollife-personal
```

필수 Worker secrets: `FIREBASE_SERVICE_ACCOUNT`(쿨라이프 전용), `ADMIN_LINK_HASH`(비공개 관리자 링크 키의 SHA-256). 선택: `KAKAO_REST_KEY`.

GitHub CLI는 명령 범위에서 `gh auth token --user minjaedy`로 얻은 개인 인증만 사용하고 전역 회사 인증을 바꾸지 않습니다. `.local/`, `.wrangler/`, `.env*`와 `node_modules/`는 커밋하지 않습니다.

Firebase 실시간 스트림 구현 참고: [공식 REST 스트리밍 문서](https://firebase.google.com/docs/database/rest/retrieve-data#section-rest-streaming).

## 견적 계산과 할인 버튼

관리자 **가격표 관리 → 자주 쓰는 할인 버튼**에서 이름·정액(원)/비율(%)·할인 값을 저장합니다. 할인 버튼은 관리자 전용 D1 설정이며, 고객에게 보이는 공통/항목별 할인 안내 문구와 별개입니다. 임의의 실제 가격이나 할인 조건은 미리 넣지 않습니다.

새 견적 승인은 현재 가격표의 단가 × 수량을 불러오고, 관리자가 기본 금액을 직접 수정할 수도 있습니다. 미등록 가격은 0원으로 간주하지 않습니다. 할인은 한 가지씩 기본 금액에 적용하며, % 할인은 원 단위 미만 버림, 최대 할인액은 기본 금액입니다. 서버가 저장된 할인과 최종 금액을 재검증하고, 설정이 바뀌었다면 재확인을 요구합니다. 확정 금액과 할인 내역은 고객의 안내 이력에 남습니다. 이미 확정된 금액은 가격표 변경만으로 바뀌지 않습니다.

로고 원본은 `public/brand-mark.svg`(웹 심벌), `public/icon.svg`(앱 아이콘)입니다. 빌드 시 PNG/마스커블 아이콘과 버전 주소를 생성합니다. 설치된 기기의 아이콘 업데이트 시점은 운영체제·브라우저에 따라 달라질 수 있습니다.

열려 있는 조회 화면은 새 버전을 1분 간격/화면 복귀 시 확인합니다. 신청 작성, 가격표 편집, 열린 대화상자가 있을 때는 자동 새로고침하지 않습니다. 사진과 API 응답은 공개 캐시에 저장하지 않습니다.
